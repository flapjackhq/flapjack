| Directory | Summary |
| --- | --- |
| scripts | Starts a stable flapjack binary for dashboard development on port 7700, keeping it independent of concurrent server code changes. |
| src | The src directory contains the TypeScript frontend for Flapjack's dashboard, organized into React Query hooks for data fetching and cache management, shared utilities and type definitions, and page components for the UI. |
| tests | The tests directory contains Playwright end-to-end UI testing infrastructure for the Flapjack dashboard, including setup/teardown projects for test data management and shared helpers for test scenarios, analytics, and tenant operations. |
| tour | The tour directory provides dashboard tour functionality, including seed data initialization and shared utilities with tour configuration constants and helper functions for managing user guided tours. |
